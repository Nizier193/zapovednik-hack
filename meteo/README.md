# Метеоархив заповедника — расчётное ядро

Пакет `meteo` — единая реализация правил импорта, контроля качества, покрытия,
агрегатов и выгрузки. Один и тот же расчёт используется графиком, таблицей,
журналом качества и Excel.

## Запуск

```powershell
# Проверка ядра против эталона архива (число строк, покрытие 420 месяцев, контрольные числа)
py -3 -m meteo.verify            # путь к CSV берётся из METEO_DATA или .data/metoo_clgz_hackathon/data
py -3 -m meteo.verify C:\путь\к\meteo_clgz_hackathon\data

# Регенерация производных JSON (series.json, exceptions.json)
py -3 -m meteo.build_json

# Локальный сервер: статика из web/ + JSON/Excel API
py -3 -m meteo.serve --port 8501 --data C:\путь\к\meteo_clgz_hackathon\data
```

Путь к архиву задаётся переменной окружения `METEO_DATA` или аргументом `--data` /
первым аргументом скрипта. В состав ZIP проекта входят производные JSON
(`web/landing/dashboard/series.json`, `exceptions.json`) — это кеш/демо-данные,
их происхождение и версия зафиксированы в самих файлах. Для проверки формул и
разработки импорта используются исходные CSV.

## API (сервер `meteo.serve`)

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/meta` | точки, параметры, версия методики |
| POST | `/api/coverage` | покрытие по суткам/месяцам |
| POST | `/api/compare` | разность Кр1 − Кр2 по общим пригодным суткам |
| POST | `/api/wind` | роза ветров (16 секторов + штиль + корзины скорости) |
| POST | `/api/raw` | исходные наблюдения (статусы, файл, строка) |
| POST | `/api/exceptions` | журнал исключений с фильтрами и постраничностью |
| POST | `/api/export.xlsx` | выгрузка .xlsx (исходные наблюдения или агрегат) |
| POST | `/api/import` | догрузка CSV (предпросмотр / подтверждение) |

## Ключевые правила

- Диапазоны включающие: воздух −50…45 °C, почва −40…45 °C, влажность 0…100 %,
  скорость 0…60 м/с, порыв 0…75 м/с, направление 0…360°, давление 940…1050 гПа.
- `параметр:причина` исключает только значение параметра; `dup_conflict` — строку
  целиком. Ноль — измерение. Пустая ячейка ≠ 0.
- Полнота суток отдельно по станции и по параметру: АМЕ-60 — 72 уникальных срока
  из 96; Кр1/Кр2 — 18 разных часов из 24. Две записи часа дают час покрытия и обе
  входят в среднее.
- Месяц валиден при ≤10 неполных суток и ≤4 подряд. Декады 1–10, 11–20,
  21–конец месяца. Среднее месяца — среднее пригодных суточных средних с равным
  весом суток.
- Направление — угол: среднее по синусам/косинусам, порог неопределённости 10⁻¹⁰,
  360° ≡ 0°. Роза строится из пригодных срочных наблюдений.
- АМЕ-60, Кр1, Кр2 — отдельные ряды. Тренд через 2021/2022 запрещён. Тренд — по
  одному календарному месяцу в разные годы, минимум 5 лет. «Среднее за выбранный
  период», не норма ВМО.

## Проверка

`meteo/verify.py` сверяет расчёт с эталоном:

- 874 560 исходных строк, 874 488 пригодных на уровне строки, 72 конфликтные.
- 420 строк станционного покрытия совпадают с `coverage_by_month.csv` (0 расхождений).
- Кр1, температура 01.01.2024: −15,89395833333333 °C (48 наблюдений).
- Кр1, температура январь 2024: −10,60166143828395 °C (31 день).
- Кр1, давление 2024: 363 дня станции, 334 дня давления, 1 362 флага `pressure_hpa:range`.
- Ветер: 359° + 1° → 0°; 90° + 270° → «среднее направление не определено».
