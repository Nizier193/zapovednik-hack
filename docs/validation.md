## Повторить проверки

Из корня проекта выполните `python tests/unit/test_weather.py`. Для тестов исходного архива задайте `METEO_VERIFY_ARCHIVE` абсолютным путём к ZIP и `METEO_DB` путём к подготовленному хранилищу. Проверки архива сравнивают 420 строк с `coverage_by_month.csv`. Искусственные случаи используют собственную временную базу для порогов 71/72, 17/18, нескольких записей в одном часу, 10/11 неполных суток, 4/5 подряд, повторной загрузки и конфликта, который меняет ранее валидный день.

При проверке в Edge открыты исходные 96 измерений с графика АМЕ-60, скачан XLSX, проверены два пригодных дня давления в апреле, сравнение двух точек и сохранение добавленной карточки после перезагрузки. В книге для сравнения отдельно проверена январская разность. Проверка догрузки выполнена на трёх реальных файлах Сокол М1 в отдельной базе.

## Маршрут демонстрации

1. Откройте «Архив АМЕ-60» и задайте 01.01.2016. Откройте точку графика или строку таблицы. Сверьте число измерений и среднее. Экспортируйте карточку в Excel.
2. Переключитесь на «Давление Кр1, 2024». Проверьте апрельский разрыв на месячном графике. В разделе «Качество» выберите Кр1, давление, апрель 2024.
3. Откройте «Поляна и поле, 2025», сравните месячные линии и суточный ход. Нулевой знак разности соответствует одинаковой температуре, положительный означает более высокую температуру Кр1.
4. В отдельном запуске импортируйте архив без `kr2_2025.csv`. Откройте режим «По последнюю доступную дату». Догрузите файл через интерфейс и повторите импорт для проверки идемпотентности.
