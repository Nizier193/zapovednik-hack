# Методика метеоархива

Версия правил `1.0`. Время как записано, часовой пояс не подтверждён. Источники — описание кейса `case-2-weather.pdf`, README и справочное покрытие из `meteo_hack_dataset.zip`.

## Пригодность записи

Один срок определяется точкой и исходной отметкой `YYYY-MM-DD HH:MM`. Повтор файла выявляется по SHA-256. Одинаковые метеозначения и флаги разных файлов дают одну запись в расчёте. При расхождении или `dup_conflict` срок исключается целиком. Исходники и альтернативные строки сохраняются.

Флаг параметра исключает только его значение. Предусмотрены отдельные причины для пустой ячейки, отсутствующей колонки, ошибки разбора и нарушения диапазона README. Разбор даты строгий. Случай с неоднозначной станцией требует выбрать её в предпросмотре. Справочный CSV покрытия не считается наблюдениями.

## Покрытие и агрегаты

- АМЕ-60 — не менее 72 уникальных сроков из 96. Сокол М1 — не менее 18 разных часов из 24. Для покрытия станции считаются сроки без конфликтов. Для параметра считаются только его пригодные значения.
- Суточное среднее — обычное среднее пригодных измерений. Медиана и экстремумы считаются на том же наборе. Несколько измерений Сокол М1 в одном часу сохраняются в суточном среднем.
- Декады имеют границы 1–10, 11–20 и 21–последний день. Месячное значение допускает не больше десяти неполных дней и четыре подряд. Проверяются все календарные дни. Частичный месяц остаётся видимым в дневной сводке и помечен в месячном ряду.
- Для декады и месяца среднее считается по дням с одинаковым весом. Медиана считается по дневным медианам, минимум и максимум выбираются среди экстремумов пригодных дней. Это проектные решения для дополнительных рядов. Без валидных дней результат пуст.
- Для часового профиля сначала усредняются значения внутри каждого часа пригодного дня. Затем часы одной позиции усредняются по дням, с указанием числа дней на каждый час. Кр1 и Кр2 сопоставляются на совпадающих датах и на парах «дата + час». Разность определяется как Кр1 − Кр2. Для месячной разности проверяется полнота пересечения.

## Многолетние ряды и ветер

Для годового хода выбранный базовый период группируется по календарному месяцу одной точки. Выводятся использованные годы. Из валидного месячного значения вычитается среднее соответствующего базового месяца. Для описательной оценки линейного тренда используется тот же календарный месяц по фактическим годам. Минимум — пять точек. Это проектное решение. Точки с разными станциями и приборами остаются отдельными рядами. Температурные выводы учитывают перерывы в наблюдениях АМЕ-60 и смену шага наблюдений Сокол М1.

Направление усредняется по единичным векторам с `atan2`. Порог результирующей длины 0,1 — проектное решение. При меньшей длине среднее направление пустое. Роза ветров содержит восемь секторов, скорости 0,5–<2, 2–<4, 4–<6 и ≥6 м/с. Штиль <0,5 м/с выводится отдельно. Знаменатель — все пригодные пары направления и скорости. При переменном шаге это частота наблюдений.

## Пересчёт

Версия архива увеличивается после транзакции импорта. Суточные агрегаты затронутых дат пересчитываются внутри той же транзакции. Декады, месяцы, сравнения и Excel используют сохранённые суточные результаты или чтение исходных строк. Для полного пересчёта создайте новое хранилище, загрузите исходный архив и файлы догрузок, затем проверьте выборки перед переключением приложения на новый файл базы.
